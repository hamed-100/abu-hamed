منصة ابو حامد لتجارة الاخشاب
=============================
الملفات كلها لازم تفضل في نفس الفولدر.

تشغيل على اللاب (للتجربة):
  افتح CMD جوه الفولدر ونفّذ:   python -m http.server 8080
  وافتح في المتصفح:             http://localhost:8080

النشر على الإنترنت (Firebase Hosting):
  firebase login
  firebase deploy --only hosting
  (ملف firebase.json جاهز في الفولدر)

بعد أي تحديث: اقفل التطبيق وافتحه مرتين، ولو الأيقونة على الموبايل قديمة امسح الاختصار وضيفه تاني.
